A record of how each assignment added a meaningful part to the same website.

The starting point

The goal was to learn web development by building, revising, and extending a real site. Instead of treating each assignment as a disconnected demo, this portfolio shows the progression from a first page to a finished, accessible Capstone.

What changed at each stage

  • Foundation: semantic HTML, CSS layout, typography, and responsive structure.
  • Site architecture: multiple pages, shared navigation, project content, and contact information.
  • Interaction: JavaScript event handling and direct DOM manipulation.
  • Communication: client-side form validation, accessible errors, and API integration.
  • Milestone: keyboard access, responsive testing, contrast review, and a final portfolio that brings the work together.
